# SHAB Legal Practice Manager

AI-powered legal practice management system for SHAB Legal Consultants FZC.

## Features

- Dashboard with real-time metrics
- Client management
- Case management
- Task tracking
- Hearing calendar
- Document management
- Payment tracking
- Quotation generator
- Legal notice generator
- AI Assistant
- Staff management
- Backup & Restore

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- IndexedDB (offline storage)
- Zustand (state management)

## Installation

```bash
npm install
npm run dev
